# Images

Biblioteka obrazów wyświetlanych graczom na żywo (przez `Fear_Live.html`).

Wrzuć tu pliki `.jpg` / `.jpeg` / `.png` / `.webp` / `.gif` (mapy, portrety, scenki) i
zsynchronizuj z GitHubem (skill `beast-feast-github-sync`) — automatycznie pojawią się
w bibliotece w Arenie Bestii ("🖼️ Biblioteka obrazów — ekran graczy"), skąd możesz
je wybrać i pokazać graczom jednym kliknięciem.

Wskazówka: trzymaj pliki rozsądnej wielkości (poniżej ~2-3 MB każdy) — gracze będą
je wczytywać na telefonach, często przez mobilny internet.
